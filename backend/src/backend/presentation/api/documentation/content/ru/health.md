Возвращает `200 {"status":"ok"}`, когда процесс способен обработать HTTP-запрос. Авторизация не требуется. Проверка не обращается к PostgreSQL, Redis или SMTP: отказ внешнего сервиса не должен означать зависание самого процесса. Используйте её для проверки liveness. Для определения готовности денежных операций используйте `/health/ready`. Ответ содержит X-Request-ID для сопоставления с логами middleware; тела и секреты запросов не записываются. Старый маршрут `/health` сохраняет тот же контракт.
