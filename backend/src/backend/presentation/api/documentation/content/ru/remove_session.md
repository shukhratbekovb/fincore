Передайте Bearer access JWT и UUID session_id в пути. user_id берётся из проверенного JWT. После блокировки пользователя и сессии проверяется принадлежность. Для отсутствующей и чужой сессии возвращается одинаковый `404 session_not_found`; чужая сессия не изменяется. Некорректный UUID даёт `422`.

Успешный отзыв возвращает `204` без тела. Повторный отзыв собственной сессии тоже возвращает `204` и сохраняет исходное время отзыва без лишней записи. Время берётся после получения блокировок. Refresh этой сессии прекращает работать, остальные сессии не затрагиваются. Уже выданный access JWT действует до своего истечения. Ответ имеет `Cache-Control: no-store`.
