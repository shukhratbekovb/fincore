Оператор добавляет виртуальные средства на выбранный кошелёк. Право хранится в серверной таблице sandbox_operators и перепроверяется под блокировкой actor; поле роли в body запрещено. SANDBOX_ENABLED по умолчанию false. Нужен заранее созданный SYS:SIM_FUNDING:{currency}. Создаются SandboxTopUp и journal DEBIT системного ASSET / CREDIT LIABILITY кошелька, обновляется баланс. Всё, включая Idempotency-Key, фиксируется одной транзакцией. Повтор возвращает прежний top_up_id. Авторизованный replay доступен и после выключения sandbox.

Требуется Bearer access JWT и активный пользователь. Денежные значения новых финансовых ответов сериализуются десятичными строками minor units; вход amount_minor принимает целое JSON-число или строку цифр, без bool/float. Валюта задаётся явно. Даты содержат timezone. Ответы, включая ожидаемые ошибки, имеют Cache-Control: no-store. Ошибки используют общий detail.code/message/errors; SQL и секреты не раскрываются.
