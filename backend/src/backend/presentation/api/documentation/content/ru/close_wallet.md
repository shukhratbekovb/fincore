Требует активный аккаунт и Bearer access JWT. Укажите UUID wallet_id в пути; JSON-тело не требуется. Владельца определяет JWT. Для чужого и отсутствующего кошелька возвращается одинаковый `404 wallet_not_found`. Кошелёк, баланс и ledger account блокируются в указанном порядке внутри одной транзакции.

Закрытие допустимо только при нулевом posted_minor. Ненулевой баланс даёт `409 wallet_balance_not_zero`, состояние сохраняется. Отсутствующий баланс или несогласованный liability account дают контролируемый `500 wallet_accounting_state_error` без внутренних деталей. При успехе кошелёк и account получают статус closed, баланс и история сохраняются. Повторное закрытие согласованного кошелька с нулевым балансом тоже успешно. Ответ — `204` без тела, с `Cache-Control: no-store`.
