Заморозить собственный кошелёк активного авторизованного пользователя. UUID кошелька передаётся в пути, тело запроса не требуется. Это действие только владельца: административная блокировка и права оператора для неё в MVP не предусмотрены.

Успешный ответ — `204` без тела, с `Cache-Control: no-store`; статус кошелька — `frozen`. Повтор такого же запроса успешен и повторно не меняет время обновления. Закрытый кошелёк возвращает `409 wallet_closed`. Чужой и отсутствующий кошельки одинаково возвращают `404 wallet_not_found`. Отсутствующий баланс или некорректный счёт обязательств возвращает контролируемую ошибку `500 wallet_accounting_state_error` без изменения состояния.

Активность пользователя проверяется под блокировкой строки, затем блокируются кошелёк, баланс и бухгалтерский счёт в порядке, совместимом с проводками. Остаток, журнал и активный счёт обязательств сохраняются. Замороженный кошелёк запрещает новые входящие и исходящие переводы и sandbox-пополнения; баланс и история доступны для чтения. Разморозка снова разрешает денежные операции. Повтор уже выполненного идемпотентного перевода возвращает прежний результат без новых проводок, даже если кошелёк позднее заморожен.
