Требует активный аккаунт и Bearer access JWT. В пути укажите UUID wallet_id, в JSON — только name. Владельца определяет проверенный JWT. Чужой и отсутствующий кошелёк дают одинаковый `404 wallet_not_found`; чужая запись не изменяется. Некорректный UUID или тело запроса дают `422`.

Имя нормализуется и проверяется теми же правилами, что при создании. Кошелёк блокируется перед проверкой принадлежности и изменением. Переименование разрешено для active и frozen, но closed возвращает `409 wallet_closed`. Валюта, номер и баланс не меняются. Успешный ответ — `204` без тела, включая отсутствие JSON null. Ответ имеет `Cache-Control: no-store`.
