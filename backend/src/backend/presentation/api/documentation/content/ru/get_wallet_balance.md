Возвращает проекцию баланса своего кошелька и её version/updated_at. as_of — метка чтения БД, а не версия journal. Пока нет holds, available_minor равен posted_minor; spendable_minor равен available только для ACTIVE, иначе 0. Чужой и отсутствующий кошелёк дают 404. Для своего кошелька пропавшие balance/account или неверные связи приводят к контролируемому 500, а не к ложному нулю. Данные читаются одним SQL snapshot.

Требуется Bearer access JWT и активный пользователь. Денежные значения новых финансовых ответов сериализуются десятичными строками minor units; вход amount_minor принимает целое JSON-число или строку цифр, без bool/float. Валюта задаётся явно. Даты содержат timezone. Ответы, включая ожидаемые ошибки, имеют Cache-Control: no-store. Ошибки используют общий detail.code/message/errors; SQL и секреты не раскрываются.
