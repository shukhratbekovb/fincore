Требует `Authorization: Bearer <access_token>` и активный аккаунт. Передайте name и необязательную currency в JSON. Валюта по умолчанию — USD, как в application-команде. Пробелы по краям имени удаляются; после нормализации допустимо 1–64 символа. Дополнительные поля, включая user_id, number и balance, запрещены. Владельца сервер получает из JWT.

В одной транзакции создаются кошелёк, WalletBalance с нулевым posted_minor и liability LedgerAccount в той же валюте. Номер генерируется на сервере; уникальность обеспечивает БД. При коллизии вся транзакция откатывается перед новой ограниченной попыткой. После commit возвращается `201` с wallet_id. Создание не идемпотентно: повтор запроса создаёт ещё один кошелёк. После потери ответа нельзя предполагать, что операция не выполнилась. Ответы имеют `Cache-Control: no-store`.
