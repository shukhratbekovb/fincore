Возвращает детали перевода только отправителю или получателю через владение кошельками. Чужой и отсутствующий перевод дают одинаковый 404 transfer_not_found. Направление incoming/outgoing/internal определяется относительно пользователя; обе собственные стороны означают internal. Данные email, IP, оператора и чужие остатки не раскрываются. Закрытие кошелька сохраняет доступ к прошлым операциям для активного владельца.

Требуется Bearer access JWT и активный пользователь. Денежные значения новых финансовых ответов сериализуются десятичными строками minor units; вход amount_minor принимает целое JSON-число или строку цифр, без bool/float. Валюта задаётся явно. Даты содержат timezone. Ответы, включая ожидаемые ошибки, имеют Cache-Control: no-store. Ошибки используют общий detail.code/message/errors; SQL и секреты не раскрываются.
