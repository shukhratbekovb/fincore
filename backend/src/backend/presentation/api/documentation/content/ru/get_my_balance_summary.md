Сводка всех своих кошельков в одном SQL snapshot, независимо от страницы списка wallets. posted/available включают active, frozen и closed; spendable учитывает только active. Итоги представлены отдельно по валютам и никогда не складываются между валютами. Необязательный currency сужает выборку. Нет подходящих кошельков — totals=[]; существующие нулевые кошельки дают нулевой total. Отсутствующий balance/account — ошибка целостности 500. Агрегат может превышать предел одного BIGINT без усечения.

Требуется Bearer access JWT и активный пользователь. Денежные значения новых финансовых ответов сериализуются десятичными строками minor units; вход amount_minor принимает целое JSON-число или строку цифр, без bool/float. Валюта задаётся явно. Даты содержат timezone. Ответы, включая ожидаемые ошибки, имеют Cache-Control: no-store. Ошибки используют общий detail.code/message/errors; SQL и секреты не раскрываются.
