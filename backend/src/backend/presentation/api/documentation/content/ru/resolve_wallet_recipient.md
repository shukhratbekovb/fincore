Находит получателя по полному номеру кошелька. Требуется Bearer access token и активный аккаунт отправителя. В body передаётся wallet_number — строка ровно из 20 ASCII-цифр. Ведущие нули сохраняются; поиск по части номера не поддерживается.

Ответ содержит только wallet_id, number, currency и owner. Поле owner — username владельца найденного кошелька, то есть получателя перевода. Доступны только активные кошельки активных владельцев, включая собственные кошельки. Для отсутствующих, закрытых или замороженных кошельков возвращается одинаковый 404 wallet_not_found.

Query читает PostgreSQL без блокировок и изменений. Результат поиска не резервирует кошелёк: CreateTransferUseCase повторно проверяет валюту, состояние, права отправителя и баланс. Для перевода frontend использует возвращённый wallet_id. Все ответы имеют Cache-Control: no-store. Redis ограничивает запросы на пользователя и IP: 30 и 100 в минуту по умолчанию. При недоступном limiter поиск не выполняется и возвращается 503. Номер передаётся в body и не попадает в URL или request metadata logs.
