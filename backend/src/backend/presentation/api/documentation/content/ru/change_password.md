Требует `Authorization: Bearer <access_token>`. Идентификатор пользователя берётся из проверенного JWT, а не из тела запроса. Передайте `current_password` и `new_password` в JSON. Текущий пароль должен совпасть с сохранённым хешем; новый должен соответствовать политике сложности. При успехе возвращается `204` без тела и отзываются все сессии пользователя. Для дальнейшего обновления токенов войдите заново. Уже выданные access JWT действуют до своего срока: HTTPBearer сейчас проверяет JWT без проверки сессии в БД. Ответ имеет `Cache-Control: no-store`.
