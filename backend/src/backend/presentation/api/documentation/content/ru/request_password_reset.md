Передайте `email` в JSON. Для любого корректного email возвращается одинаковый `202` с одинаковым сообщением: ответ не подтверждает существование аккаунта. Для активного пользователя с установленным паролем в одной транзакции создаются challenge и outbox-задание. Worker отправляет ссылку на `FRONTEND_PASSWORD_RESET_URL#token=...`; `202` не гарантирует доставку. До подтверждения пароль и сессии не меняются. По умолчанию ссылка действует 15 минут (`PASSWORD_RESET_TTL`).

Лимиты общие для процессов API: 10 запросов в минуту на IP и 3 запроса за 15 минут на email, включая неизвестные адреса. При превышении вернётся `429` с `Retry-After`. IP определяется через доверенный proxy; не доверяйте произвольному X-Forwarded-For. Успешный ответ задерживается минимум на 500–600 мс после начала use case для уменьшения временных различий; это не гарантия постоянного времени. Ответы не кешируются.

Лимиты проверяются через общий Redis. При его недоступности возвращается `503 rate_limiter_unavailable`; операция не выполняется.
