Отзывает сессию, связанную с переданным refresh-токеном. Для выхода можно использовать и ранее
заменённый токен этой сессии. Заголовок с access-токеном не нужен.

```bash
curl -X POST http://127.0.0.1:8000/v1/auth/logout \
  -H 'Content-Type: application/json' \
  -d '{"refresh_token":"example-refresh-token"}'
```

Для корректного запроса ответ — `204` без тела, в том числе при неизвестном токене,
отсутствующей или уже отозванной сессии. Повторять запрос безопасно. Неверный формат возвращает `422`.
Отзывается только связанная сессия; другие входы остаются действующими.

Дальнейшее обновление токенов этой сессии запрещается. Уже выданные access JWT автоматически
не аннулируются: немедленный отзыв доступа требует проверки состояния сессии в защищённых эндпоинтах.
После успешного ответа удалите оба токена из локального хранилища клиента.
