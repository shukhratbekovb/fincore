Передайте Bearer access JWT. Сервер получает владельца из JWT, блокирует строку пользователя и в одной транзакции отзывает все его ещё не отозванные сессии. Время прежних отзывов сохраняется. При отсутствии сессий запрос также успешен. Ответ — `204` без тела; ответ не содержит JSON null.

Операция включает сессию, из которой пользователь начал действие. Старые refresh-токены больше не позволяют обновить доступ; для новой сессии потребуется login. Ранее выданные access JWT продолжают действовать до истечения срока, поскольку пока нет проверки сессии при каждом защищённом запросе. Новые входы после операции создают новые сессии. Ответ имеет `Cache-Control: no-store`.
