Использует токен подтверждения регистрации, устанавливает выбранный пароль и активирует аккаунт.
Токен и пароль передаются в JSON-теле. Открытие ссылки GET-запросом не подтверждает аккаунт.

Пароль должен содержать 8–256 символов, строчную букву, заглавную букву, цифру и знак
ASCII-пунктуации, например `!`, `_` или `-`. Пробелы в пароле не удаляются.
При успехе возвращается `204` без тела; для получения токенов сессии нужно отдельно выполнить вход.

```bash
curl -X POST http://127.0.0.1:8000/v1/auth/confirm \
  -H 'Content-Type: application/json' \
  -d '{"token":"example-confirmation-token","password":"ExamplePassword1!"}'
```

Замените условный токен реальным токеном регистрации. Неверное значение или другое назначение токена
даёт `400 invalid_confirmation_token`; истёкший срок — `400 confirmation_token_expired`;
повторное использование — `400 confirmation_token_used`. Отклонённый новый пароль возвращает `422`
и не использует подтверждение. Если аккаунт больше не ожидает подтверждения, вернётся `409`;
если пользователя нет — `404`. Эндпоинт предназначен только для регистрации, не для сброса пароля или платежей.
