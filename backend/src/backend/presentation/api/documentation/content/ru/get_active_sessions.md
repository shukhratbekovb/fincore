Требует `Authorization: Bearer <access_token>`. UUID владельца берётся из проверенного JWT, после чего проверяется наличие и активность пользователя. Ответ `200` содержит массив собственных сессий. При отсутствии активных сессий возвращается `[]`, без ошибки `404`.

В выборку входят только сессии с revoked_at = null и expires_at > now; при равенстве срок уже истёк. Сортировка: created_at DESC, id DESC. Ответ показывает исходные IP/User-Agent и данные последнего успешного refresh. last_used_at не отражает каждый HTTP-запрос. User-Agent задаётся клиентом и не гарантирует модель устройства. Секреты сессии и refresh-токены не возвращаются. Ответ имеет `Cache-Control: no-store`.
