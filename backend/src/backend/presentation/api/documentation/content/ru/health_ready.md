Проверяет PostgreSQL через SELECT 1 и Redis через PING параллельно, с отдельным ограничением времени HEALTH_CHECK_TIMEOUT (по умолчанию 2 секунды). При успехе обеих проверок возвращает 200, иначе 503; тело содержит status и checks.postgres/checks.redis со значениями ok/unavailable. Подробности ошибок, адреса и секреты не возвращаются. SMTP не проверяется: доставку выполняет отдельный outbox worker. Endpoint не изменяет бизнес-данные и доступен без JWT. Ответы имеют Cache-Control: no-store. Docker использует этот маршрут для проверки готовности API; статус unhealthy сам по себе не перезапускает контейнер.
