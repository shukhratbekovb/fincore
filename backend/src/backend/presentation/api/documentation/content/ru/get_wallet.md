Передайте Bearer access JWT и UUID wallet_id в пути. Пользователь проверяется на существование и активность. Кошелёк выбирается по wallet_id и user_id из JWT непосредственно в SQL, поэтому чужая запись не попадает в преобразование DTO. Чужой и отсутствующий кошелёк дают одинаковый `404 wallet_not_found`. Невалидный UUID возвращает `422`.

Успешный ответ `200` содержит метаданные и balance_minor. Баланс — целое число минимальных единиц currency. Номер возвращается строкой из 20 цифр с сохранением ведущих нулей. Запись баланса читается через LEFT JOIN: если у собственного кошелька нет balance, возвращается контролируемый `500 wallet_accounting_state_error`. Нулевой баланс допустим. Можно читать свои active, frozen и closed кошельки. Запрос не делает commit и не использует FOR UPDATE. Ответ имеет `Cache-Control: no-store`.
