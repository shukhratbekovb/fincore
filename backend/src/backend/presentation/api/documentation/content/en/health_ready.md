Probes PostgreSQL with SELECT 1 and Redis with PING concurrently, each bounded by HEALTH_CHECK_TIMEOUT (default 2 seconds). Both must succeed for HTTP 200; otherwise returns HTTP 503. The body contains status and checks.postgres/checks.redis using ok/unavailable. Exception details, addresses and credentials are never returned. SMTP is excluded because a separate outbox worker delivers emails. This public endpoint requires no JWT and changes no business data. Responses use Cache-Control: no-store. Docker uses it for API readiness; an unhealthy status alone does not restart a container.
