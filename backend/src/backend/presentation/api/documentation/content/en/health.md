Returns `200 {"status":"ok"}` when the process can handle an HTTP request. Authentication is not required. This probe does not access PostgreSQL, Redis or SMTP: an external service failure does not imply that the process itself has stopped responding. Use it for liveness; use `/health/ready` to check dependency readiness. Responses include X-Request-ID for correlation with middleware logs, without logging request bodies or secrets. The existing `/health` route keeps the same contract.
