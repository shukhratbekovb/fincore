An authorized operator adds virtual funds to a wallet. Permission is stored server-side in sandbox_operators and rechecked under the actor row lock; client role flags are forbidden. SANDBOX_ENABLED defaults to false. A pre-provisioned SYS:SIM_FUNDING:{currency} account is required. One transaction stores the operation, system ASSET DEBIT / wallet LIABILITY CREDIT journal, updated balance and Idempotency-Key result. Replay returns the same top_up_id. Authorized replay remains available after disabling sandbox.

Requires a Bearer access JWT and an active user. Monetary fields in these new financial responses are decimal minor-unit strings. Request amount_minor accepts a JSON integer or digit string, never bool/float. Currency is explicit. Timestamps are timezone-aware. Responses including expected errors use Cache-Control: no-store. Errors use the shared detail.code/message/errors envelope without SQL details or secrets.
