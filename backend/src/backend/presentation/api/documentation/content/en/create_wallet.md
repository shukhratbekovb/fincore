Requires `Authorization: Bearer <access_token>` and an active account. Send name and optional currency in JSON. Currency defaults to USD, matching the application command. Leading and trailing name whitespace is removed, leaving 1–64 characters. Extra fields, including user_id, number and balance, are forbidden. The JWT identifies the owner.

One transaction creates the wallet, a WalletBalance with zero posted_minor and a liability LedgerAccount in the same currency. The server generates the number; the database enforces uniqueness. A collision rolls back the whole transaction before a bounded retry. Success returns `201` with wallet_id after commit. Creation is not idempotent: repeating a request creates another wallet. A lost response does not mean the operation failed. Responses use `Cache-Control: no-store`.
