Requires `Authorization: Bearer <access_token>`. The user identifier comes from the verified JWT, never from the body. Send `current_password` and `new_password` as JSON. The current password must match the stored hash; the new password must meet the complexity policy. Success returns `204` without a body and revokes all user sessions. Sign in again to obtain refreshable tokens. Previously issued access JWTs remain valid until expiry because HTTPBearer currently validates JWTs without a database session check. The response uses `Cache-Control: no-store`.
