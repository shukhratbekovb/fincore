Returns an owned wallet balance projection and its version/updated_at. as_of is a database read timestamp, not a journal version. Without holds available_minor equals posted_minor; spendable_minor equals available only for ACTIVE wallets, otherwise zero. Missing/foreign wallets return 404. Missing or inconsistent accounting projections on an owned wallet return controlled 500 instead of a false zero. Values come from one SQL snapshot.

Requires a Bearer access JWT and an active user. Monetary fields in these new financial responses are decimal minor-unit strings. Request amount_minor accepts a JSON integer or digit string, never bool/float. Currency is explicit. Timestamps are timezone-aware. Responses including expected errors use Cache-Control: no-store. Errors use the shared detail.code/message/errors envelope without SQL details or secrets.
